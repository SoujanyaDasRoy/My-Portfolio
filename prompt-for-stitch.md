# Portfolio Website Design Brief

## Project Info
**Type:** Personal portfolio website
**Goal:** Get hired / attract freelance clients

## Target Audience
- Startups and indie founders needing web apps
- Small businesses needing websites
- Recruiters (remote + Kolkata-based)

## Developer Profile
Full-stack MERN developer who also builds WordPress/Elementor websites. Perfectionist, creative, uses AI tools to build efficiently. Focuses on real-world solutions, not just code.

## Visual Style
- Modern SaaS-inspired (Stripe-like)
- Light + dark mode with toggle
- Smooth animations, scroll-based storytelling
- Colorful but clean
- Dark mode: glowing neon effects
- Light mode: minimal, elegant

## Page Sections

### 1. Hero
- Headline: "I build powerful web apps and high-converting websites"
- Subtext: Speed + creativity + real-world impact
- Buttons: "Hire Me" + "View Work"

### 2. My Story
Animated scroll-based journey:
- Started building apps for friends
- Focused on control, privacy, custom tools
- Now builds full-stack apps + business websites

### 3. Projects (2 Categories)

**A. Web Applications**
- AI SaaS Tool
- Smart E-commerce Platform
- Problem-solving Tool
(Each: Problem → Solution → Result, tech stack, preview, links)

**B. Business Websites**
- WordPress + Elementor projects
- Clean UI, conversion-focused, fast delivery

### 4. Skills (Visual, Not a List)
- Full Stack (MERN)
- Website Building (WordPress, Elementor)
- AI-assisted development tools

### 5. How I Work
- Fast execution
- Clean code
- Results-focused

### 6. Contact
- Headline: "Let's build something powerful"
- Email + GitHub link

## Design Features
- Smooth scroll animations
- Hover/micro-interactions
- Cursor effects
- Section transitions
